# Terminology Standardization

| Preferred term | Rejected variants | Reason |
| --- | --- | --- |
| molecular program | axis, signature, module, endotype for final findings | Keeps biological interpretation separate from mathematical factors and failed endotype framing. |
| continuous molecular program | discrete endotype, patient class | Reflects the stable representation supported by the analysis. |
| tissue-state program | genetic subtype, germline-defined subtype | Preserves the tissue-state versus inherited-liability distinction. |
| axis-specific genetic anchoring | genetic validation, genetic endotype, genetic subtype | Describes the tested genetic support without overclaiming. |
| overall psoriasis susceptibility | psoriasis genetic axis, overall genetic layer | Names the GWAS exposure directly. |
| shared genetic architecture | systemic genetic layer, multisystem liability architecture | Standard genetics phrase with less abstraction. |
| local genetic correlation | local sharing, local architecture when ambiguous | Keeps LAVA result terminology precise. |
| shared regulatory signal | causal mediator, therapeutic target | Keeps coloc interpretation conservative. |
| contextual cellular/spatial evidence | definitive localization, validated mechanism | Preserves evidence strength. |
