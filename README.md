# Psoriasis molecular heterogeneity and multisystem shared genetics

This repository accompanies the Journal of Dermatological Science submission, “Molecular heterogeneity and multisystem shared genetic architecture define distinct biological layers of psoriasis.”

## Current reproducibility release

GitHub release [v1.1.0](https://github.com/seefreewind/psoriasis-molecular-heterogeneity-comorbidity/releases/tag/v1.1.0) contains the curated analysis scripts, configuration and environment files, five main figure exports, and their aggregate source tables. The package excludes raw expression/genotype data, controlled-access source files, GWAS summary statistics, GTEx BESD resources, and LD reference panels. It includes unlabeled, de-identified donor-level derived scores used to reproduce the Figure 3 points.
