# v1.0.0-submission release notes

This release archives the submission-stage code, processed source data, figure source data, manuscript-generation scripts and audit reports for the Communications Biology manuscript:

Molecular heterogeneity and multisystem shared genetic architecture define distinct biological layers of psoriasis

Zenodo DOI: https://doi.org/10.5281/zenodo.22020396

## Included

- Final language-polished main manuscript source and Word file.
- Final Supplementary Information source and Word file.
- Main figure source data and figure-generation scripts.
- Supplementary tables, supplementary data and supplementary figure source data.
- Analysis scripts under `src/`.
- Environment specification under `environment/`.
- Submission declarations, cover letter draft and final checklist under `submission/`.
- Submission-lock audit reports under `reports/`.

## Not included

- Original public datasets that should be obtained from GEO, ArrayExpress, GWAS Catalog, GTEx or original study providers.
- Controlled-access, license-restricted or source-term-restricted resources.
- Raw GWAS summary statistics, LD references, GTEx BESD files and large regenerated intermediate files.
- Rendered QA images, local Office scratch files, AppleDouble metadata files and local environments.

## Reproducibility note

The repository provides processed result summaries and source data required to reproduce the reported manuscript tables and figures. Some upstream genetics workflows require external software, reference panels and source data access permissions, as described in the manuscript, supplementary methods, configuration files and audit reports.
